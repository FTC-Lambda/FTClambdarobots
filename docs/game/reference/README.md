# Official BIOBUZZ documents

Local copies of the official FIRST documents for the 2026–2027 season,
downloaded 2026-11-08. The PDFs and ZIP are **git-ignored** because they are
large and FIRST revises them weekly. Run `./fetch.sh` from this folder to
download the current versions.

Hub for everything: https://ftc-resources.firstinspires.org/ftc/game
(`https://ftc.game` redirects there).
